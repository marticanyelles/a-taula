# A taula!

App de menús de casa en un sol fitxer HTML (`index.html`). Funciona al navegador (Chrome o Edge) i llegeix i desa en un Excel que tria cada usuari al seu dispositiu.

Aquí només hi ha l'app: les dades (menús, inventari, registre) no es publiquen mai; són a l'Excel i al navegador de cada dispositiu.
